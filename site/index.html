From repository to explanation

The agent writes.
xpl checks.

The checks verify source locations and freshness. The author still has to get the explanation right.

  1. Index the repository

    xpl finds files, symbols and references. References say whether they come from a precise tool or a heuristic.

  2. The agent writes a patch

    You ask a question. The agent adds diagrams, short explanations and anchors to the code.

  3. xpl checks source anchors

    Each anchor must resolve to real code and match the current source. Missing or stale links block a ready export; the explanation still needs review.

  4. Read it. Share it.

    Explore the diagrams beside the source, follow a guided tour, or export one HTML file with the code inside.

Try it on your repository

Start with a question.

Install from npm with Node 22.12 or newer. The source is available on GitHub.

Read the getting started guide ↗

Install xpl and its skill for Codex:

npm install --global @krimvp/xpl
xpl skill install --agent codex

Ask Codex to use the skill:

Use code-explainer to explain how a failed job gets retried.

For other harnesses, choose --agent claude, --agent pi, --agent droid, or --agent devin. Run Devin's installer in the target repo and install the CLI in its remote environment. See the getting started guide for details.

Or build from a checkout of xpl:

npm install && npm run build
npm pack ./packages/cli/dist
npm install -g --ignore-scripts ./krimvp-xpl-0.2.2.tgz
xpl skill install

The skill indexes your project, writes a patch and checks it before opening the guide.
